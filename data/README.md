# Data

This project uses a modified dataset from a previous study examining young primary school children's academic self-concept, subject preferences and skills. The 
dataset contains self-concept, preferences and skill tests about mathematics, reading and writing measured in autumn and spring semesters.

The original dataset is not included in this repository due to data privacy considerations.

The analysis requires the original SPSS dataset (`dataset.sav`). Users must obtain authorised access to the dataset before running the Python script.
