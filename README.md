# Quantitative Data Analysis

## Project Overview

This project presents an applied quantitative research study using statistical analysis and modelling techniques. It demonstrates the application of Python and Mplus in data preparation, statistical analysis, and empirical research.

The project combines descriptive statistics, regression analysis, and Confirmatory Factor Analysis (CFA) to investigate relationships between research variables and evaluate measurement models.

## Research Objectives

- Explore the characteristics and distributions of the research variables.
- Examine relationships between variables using regression analysis.
- Evaluate the measurement model through Confirmatory Factor Analysis (CFA).
- Present statistical findings through structured tables and visualizations.

## Methodology

The project incorporates three main analytical approaches:

### 1. Descriptive Statistics
Statistical summaries are used to examine the distributions and characteristics of the variables.

### 2. Regression Analysis
Regression models are estimated to investigate relationships between relevant research variables and evaluate their statistical significance.

### 3. Confirmatory Factor Analysis (CFA)
CFA is employed to assess the measurement model, examine factor loadings, and evaluate model fit.

## Tools & Technologies

- **SPSS:** Data processing and data cleaning.
- **Python:** Data processing, statistical analysis, and results generation.
- **Mplus:** Confirmatory Factor Analysis (CFA).
- **Excel:** Presentation and organization of statistical results.
