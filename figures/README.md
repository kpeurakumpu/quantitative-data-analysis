# Figures

This folder contains visualisations generated using Python as part of the quantitative data analysis.

## Included figures

- `correlation_matrix.png` – Pearson correlation matrix showing relationships between the study variables.
- `regression_coefficients.png` – Regression coefficient plot showing the estimated effects of autumn mathematics skills and mathematics interest on spring mathematics skills, including 95% confidence intervals.
- `cfa_model.png` – Confirmatory factor analysis (CFA) path diagram illustrating the two latent mathematics-interest factors, their observed indicators, and the relationship between the factors across autumn and spring.

All figures were generated using Matplotlib in Python and are based on the analyses presented in the research report.
